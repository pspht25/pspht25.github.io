CH 1

成像与边缘定位：每一行找一个 0.5 交点

虚拟相机按 亮度 = 黑白覆盖比例经高斯模糊 + 噪声 生成斜边照片。算法第一步：对每一行，把像素灰度归一化成 0~1（减黑基准、除以亮暗差），再找归一化亮度恰好等于 0.5 的位置——那就是该行的黑白交界。

为什么是 0.5？边缘的几何位置定义为"黑白各占一半"处，对应归一化亮度 0.5。演示版用 0.1~0.9 区间线性插值找交点；标准做法（ISO 12233）对整段过渡做曲线拟合再取 0.5，抗噪更强、定位可精确到百分之几像素。
CH 2

沿边缘过采样提取 ESF：把千行点云堆成一条细曲线

每行每个像素都变成一个点：横轴 = 到该行交点的距离，纵轴 = 归一化亮度。边缘垂直（θ=0）时每行的点完全重合，只有 1 像素间隔；斜 θ 时各行交点逐行错开 tanθ，1/tanθ 行恰好凑满一个像素周期——点云在横轴上被加密成 0.0875 px 步长（θ=5°）。按 tanθ 宽度分箱取平均，得到 ESF。

分箱示意（过渡区中段的 6 个 bin）
bin 距离区间 (px)样点数均值 = ESF
锐化 = 人造过冲欠冲：拖动左侧「ISP 锐化强度」滑杆（USM，半径 1.2 px，作用在加噪之后的像素上）。ESF 会在爬顶后鼓出超过亮平台的小包（过冲）、起步前先凹出低于暗平台的小坑（欠冲）；差分后 LSF 主瓣旁长出负瓣和正旁瓣；FFT 后高频段 MTF 被人为抬高甚至上翘——"锐"是算法画的边，不是镜头真能解析。徽章实时报过冲/欠冲幅度；ISO 12233 类标准要求报 MTF 前先检查它，超阈值应关锐化重测。另注意：噪声残差本身也会带来 ~1% 的假过冲（把噪声拖到 0 就干净了），锐化过冲会明显得多。
过采样的全部来源：tan5° ≈ 0.0875，每 11.4 行交点错开整整 1 像素后相位循环——这 11 行合起来把 0~1 px 之间所有亚像素位置摸了一遍。把 θ 拖到 0°：每行交点相同、点云退回 1 px 间隔，过采样消失；这就是斜边存在的意义。
CH 3

差分求导得 LSF：过渡有多陡

ESF 只告诉你亮度"怎么爬"，LSF 告诉你爬得有多陡：相邻 bin 的 ESF 值相减。S 形爬坡线求导后变成钟形——钟形越窄，边缘越锐利；镜头把干脆的跳变拖成缓坡时，钟形就又矮又胖。

差分示意（峰值附近 6 个 bin）
距离 d (px)ESF S[d]ESF S[d+Δ]ΔS = LSF
求导即差分。LSF(d) ≈ S(d+Δ) − S(d)，Δ 就是分箱宽度。标准实现里对差分核还有细微修正（前后差分取平均），演示版用最直观的前向差分——在 0.0875 px 的细分格上，它与真值的差别在低频段小于 0.1%。

对暗号机：探针怎么给每个频率打分

MTF 曲线的每一点都是这样来的：派一条该频率的理想条纹探针 cos(2πf·d)，与 LSF 逐点相乘再求和——同相得多、反相得少甚至为负。拖动探针频率，看得分在下方一点点长成第④步那条 MTF 曲线。

CH 3⁺⁺

为什么这个得分就是对比度保留率——箭头合成证明

把"对暗号得分"和"条纹拍完剩几成对比度"焊死的四步：① 模糊 = 按 LSF 加权平均（每个物点的像散成 LSF 斑，线性叠加）→ ② 条纹过加权平均仍是同频条纹，只改幅度和相位（同频正弦相加的铁律）→ ③ 每个 LSF 权重是一支箭头：长度=权重，转角=360°×f×挪位；箭头首尾相接，合矢量的长度就是输出条纹幅度 → ④ 除以"箭头全排齐"（f=0）时的长度，就是对比度保留率。拖动频率，看箭头从排齐到卷成一团。

每挪 1px 转角 = 360°×f = — 参与合成的箭头数 = — 合矢量长度 = 输出幅度 = — 条纹相位挪动 = — MTF(f) = 长度 ÷ 全排齐长度 = — 条纹带输出对比度 = —
三个必看状态：① f 拖到 0：所有箭头排齐朝右，合矢量顶到虚圆，输出=输入——最粗的条纹毫无损失，这就是分母 |X(0)|；② f 升高：每支箭头多转 360°×f，链开始卷曲，合矢量变短——条纹被磨矮；③ σ 拖大：参与卷曲的箭头更多、更早卷紧——"糊 = 高频先死"的几何本体。合矢量长度 ÷ 虚圆半径 = 对暗号机里的 MTF(f)——同一组权重，两种叙述，一个答案。对暗号机里的红绿柱相消，就是这里的箭头相消在实轴上的投影。
CH 4

加窗 FFT 得 MTF：各种粗细的线条还剩多少对比度

对 LSF 做Hann 加窗 → 补零到 2048 点 → FFT → 除以零频值归一化，得到 MTF(f)：0 频处为 1，随频率衰减。MTF50 是曲线穿过 0.5 的频率——镜头测试最常用的单一读数。噪声会在高频段把曲线"翘"起来（噪声不挑频率），这是真实测量里常见的现象。

为什么除以零频？FFT 的直流分量代表整体透过率（镜头脏一点它就低），它与"清晰不清晰"无关。除以 MTF(0) 后只留下"随频率衰减的形状"，不同设备才有可比性。LW/PH = MTF50 × 2 × 水平像素数：竖直斜边测的是水平方向分辨率。

动手做三个实验

参数都活着——点右上角 ⚙ 打开控制台拖动它们，观察下面三件事，比读十遍文字都直观。

实验 1 · 角度 ↔ 过采样

把 θ 从 5° 拖到 0°

看第②步：灰空心点不变（单行信息就那么多），青色点云从密集变回 1 px 稀疏——过采样倍数 11.4× 一路掉到"无新相位"。再拖到 0.5°：bin 变得比数据还细，ESF 满是锯齿，MTF50 读数甚至直接失效——角度太小，行数永远不够填满分箱。

实验 2 · 模糊 ↔ MTF50

把 σ 从 1.0 拖到 2.0

第③步钟形变胖，第④步整条 MTF 曲线下压，MTF50 从约 0.19 掉到约 0.09 cy/px。这就是"镜头模糊一倍，读数腰斩"的量化版本。

实验 3 · 噪声 ↔ 高频翘起

把噪声从 2 拖到 8

ESF 点云开始毛糙，MTF 高频段翘离理论虚线——噪声不挑频率，把高频对比度"垫"了回去。真实测量里这就是为什么要把噪声、Light falloff 控制在标准范围内。

与标准实现的关系：本演示按 ISO 12233 斜边法的核心链路（逐行定位 → 距离堆叠分箱 → 差分 → 加窗 FFT → 零频归一）用简化实现复现：0.5 交点用线性插值而非曲线拟合，未做像素孔径与差分核的频响补偿，黑/白基准按每行两侧各 5 列估计。用于建立直觉足够精确；工程测量请使用标准软件。理论对照线基于高斯 PSF 假设：ESF=Φ(d/σ)，LSF=高斯，MTF=exp(−2π²σ²f²)。
