环形灰阶卡：SNR 是怎么测出来的

Imatest 式相机 IQ 测量演绎：把「已知亮度」摆进场景，从相机的输出数字反推它的性格——灰阶怎么抓、OECF 怎么画、信噪比怎么算、那个神秘的 0.13 从哪来、多帧怎么把两种噪声分开。本页与其他演示页完全独立。

① 为什么拍一张灰阶卡

相机是个黑盒：场景亮度进去，数字（DN, digital number 0~255）出来。想知道它的性格，最直接的办法是喂给它一组亮度已知的输入，再看它吐出什么。Imatest 生态的做法就是把一系列反射率（或透射率）精确已知的灰块 patch 印在一张卡上，拍下来，逐块统计。

d = log₁₀(1/R)，R = 10−d

密度 d 每加 1.0，反射率 ÷10，光量直降 20dB / 3.32 档。一张 80:1 的反射卡，密度从 0.1 排到 2.0，正好横跨日常场景的中间 6 档多。

同一 20-patch 几何有五种对比度变体：低 20:1、标准 80:1、160:1（eSFR ISO 用）、高 1000:1，以及 Image Engineering TE241 透射卡（12600:1，密度到 4.1）。TE264 与其几何完全一致。

🎯 圆环排布：防渐晕

镜头渐晕从中心向外变暗。一条直线排 patch，同密度的块会因位置不同而读数不同；环形排列让同环 patch 离中心等距，渐晕变成环内对称的偏置——建模得掉、去除得掉。36-patch DR 卡官方说法就是「近乎圆形排列使渐晕影响最小」。

📏 patch 大：样本多

噪声是统计量，样本越多估计越稳。噪声卡的 patch 特意做得比分辨率卡大——单帧内就有几百个样本，配合标准要求的 ≥8 帧，σ 才收敛。

⚖️ 中性灰背景

整卡背景是中性灰（输出约 110~130 / 8bit sRGB）。自动曝光和自动白平衡不会在卡上「跑偏」，不同相机、不同批次拍的读数才可比。

② 亲手合成一张「照片」

真实测量要真的拍卡；我们把相机塞进浏览器：15 个 patch 的场景亮度已知（就按 ISO 15739 noise target 的密度表），模拟「传感器 + ISP」生成 8bit 灰阶照片。后面所有测量都对着这张照片做——这就是 Imatest 分析软件眼里看到的原始输入。

DN = 255 · ( S·(1+PRNU·g) + n )1/γ，其中 n ~ N(0, √(S·c+σr²))

15 个 patch = 12 外圈（近椭圆）+ 3 中心行，密度 0.1 → 2.0；背景密度 0.62。悬停可看 patch 读数。

数字是模拟的，物理是真的：散粒噪声 √(S·c)、读出噪声 σr、逐像素固定增益差（PRNU）、gamma 编码、镜头渐晕，一个不少。曝光 E 调太大，亮端 patch 会顶到 255 饱和——这正是测量时要避免的。

③ 抓取 patch：ROI 与 fill factor 陷阱

Imatest 的分析流程：选卡型 → 粗裁剪 → 自动定位或微调每个 patch 的 ROI → 用 fill factor 控制采样框占 patch 的比例。fill 太大，采样框会碰到 patch 边缘、混进背景像素，σ 直接虚高；fill 太小，样本变少、σ 估计抖动。Imatest 文档的原话：fill factor 高于 0.65 不再推荐，因为采样区可能太贴边。

⑤ SNR 曲线与那个「0.13」

每个 patch：信号 = 线性域均值，噪声 = 去低频后的 rms，SNR = 信号/噪声。15 个点连成 SNR–亮度曲线。但报告里只需要一个数——在哪报？ISO 15739 的三步法：

1️⃣ 提取 Lref

使三通道任一达到 DN=245 的最低场景亮度（245 是 8bit sRGB 的白裁剪参考）。

2️⃣ 计算 LSNR

LSNR = 0.13 × Lref
0.13 的由来：18% 灰卡 + 相机给高光留 140% 余量 → 0.18 / 1.4 ≈ 0.13。报告的就是「典型中间调」处的信噪比。

3️⃣ 曲线插值

在 SNR–亮度曲线上，按 log-log 插值取 LSNR 处的值，换算 SNRdB = 20·log₁₀(S/N)

渐晕开着时试试关掉它：patch 内亮度自带梯度，直接求 rms 会把「大尺度明暗」误当噪声——σ 虚高、SNR 偏低。标准附录 C 专门规定先去掉低频起伏再算噪声（2023 版从建议升级为强制）。

⑥ 多帧分离：时间噪声 vs 固定模式噪声

⏱️ 时间噪声（Temporal）

每帧都不同：散粒噪声、读出噪声。同一 patch 的帧间均值波动就是它。多帧平均的 √N 收益只对它有效。

🧱 空间噪声（Spatial / FPN）

每帧都一样：像素间的固定增益差（PRNU）。拍 N 帧再平均，平均图里 patch 内仍在的波动就是它——平均不掉，只能标定。

拍 N 帧：帧间波动 → 时间噪声 σt；N 帧平均图内的像素波动 → 空间噪声 σs；且 σtotal² = σt² + σs²。ISO 15739 要求 ≥8 帧才能可靠分离。

⑦ 动态范围：曲线的两个尽头

DR = Lsat / Lmin：上端是还能测的极限（DN 顶格对应的场景亮度），下端是 SNR 跌到 1（0dB）的亮度。低光端噪声恒定（读出噪声地板），SNR ∝ L 成直线——ISO 15739 允许把这根直线外推到 0dB 找 Lmin（标准记法 Lmin = σ(d=2)/g(d=2)）。
